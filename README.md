I'm **Raven**, founder of **[Rudy Systems](https://rudy.systems)**. I build tools for systems programming, network reconnaissance, and security research, with a focus on evidence you can inspect.

My main focus is **Rudy Evidence**, a shared security SDK with a **C++20** core, a **C ABI**, and **C# and Python** bindings. I also build endpoint research tools, a Linux security workbench, and focused tools for HTTP/TLS, DNS, and public-source intelligence.

## Selected work

<a href="https://github.com/r4venrudy/rudy-evidence"><img src="https://raw.githubusercontent.com/r4venrudy/r4venrudy/main/assets/evidence.svg" alt="Rudy Evidence — Shared security SDK. C++20 core, C ABI, C# and Python bindings. Developer preview." width="100%"></a>

**[Rudy Evidence](https://github.com/r4venrudy/rudy-evidence)** is the shared foundation for my security tools: a native SDK that normalizes scanner findings, redacts recognized secret patterns, merges exact duplicates, compares baselines, and exports SARIF.

**C++20 · C ABI · C# · Python** — seven report adapters, offline processing, and integrations in Web Audit, Sentinel, and Central. **v0.1.0 / developer preview; MIT licensed.**

[Explore the SDK](https://github.com/r4venrudy/rudy-evidence) · [Download the preview](https://github.com/r4venrudy/rudy-evidence/releases/tag/v0.1.0-preview) · [Build and test status](https://github.com/r4venrudy/rudy-evidence/actions/workflows/ci.yml)

## What I'm building toward

- **Closer to the system:** native components, documented OS interfaces, and bounded event processing.
- **Shared foundations:** reusable libraries, stable contracts, and evidence that moves between tools.
- **Clearer investigations:** traceable observations, replayable evidence, and useful exports.
- **Tools that hold up:** reproducible builds, meaningful checks, and explicit validation status.
